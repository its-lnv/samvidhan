# Page Styles

Keep page-specific styles here when extracting inline `<style>` blocks from the existing pages.

Recommended ownership:

- `home.css`: `index.html`
- `rights.css`: `rights.html`
- `articles.css`: `articles.html`
- `cases.css`: `cases.html`
- `crimes.css`: `crimes.html`
- `freedom.css`: `freedom.html`
- `helpline.css`: `helpline.html`
- `quiz.css`: `quiz.html`
- `survey.css`: `survey.html`
- `results.css`: `results.html`

Do not move specialized styles into the shared files unless they are used by more than one page family.
